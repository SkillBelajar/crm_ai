# .ai-project-memory.md — Continuous Project Memory

## 1. Identitas & Visi Proyek (5W + 1H)
*   **What:** SaaS CRM Psikologis *"Pendengar & Pengendali"* (MindControl CRM). Alat bantu percakapan taktis berbasis AI Mandiri (BYOK) yang dirancang untuk para negosiator, konsultan, dan tim sales tingkat eksekutif.
*   **Why:** Mencegah sindrom "bakar lilin" (energi tim terkuras melayani prospek tanpa komitmen). Membalik dinamika percakapan dengan teknik mendengarkan aktif 80%, filtrasi *Conditional Yes*, dan penguncian komitmen dalam siklus 7 hari.
*   **Who:** Pengusaha solo, konsultan bisnis, agensi, dan tim sales B2B berenergi tinggi.
*   **Where:** Self-hosted / Cloud (Laravel 13 FrankenPHP Octane containerized), dapat diakses di jaringan lokal maupun tunnel publik (`https://crm.pawandigital.id/`).
*   **When:** Pembangunan bertahap 9 Slice — **Versi Aktif: 1.0 (Production Ready, Selesai 100%)**.
*   **How:** Didukung AI Mandiri (BYOK - Bring Your Own Key) yang mendukung endpoint lokal / remote OpenAI-compatible, arsitektur event-driven ultra-cepat via Laravel Octane, Livewire 3, dan Tailwind CSS v4.

---

## 2. Tech Stack & Environment
*   **Framework:** Laravel 13 + Laravel Octane (FrankenPHP worker, PHP 8.4).
*   **Frontend:** Livewire 3 + Alpine.js + Tailwind CSS v4 (@custom-variant dark, JetBrains Mono & Plus Jakarta Sans).
*   **Authentication & Roles:** Multi-Tenancy / RBAC sederhana (`admin` & `user`), middleware `role` (`EnsureUserHasRole`), session driver `redis`.
*   **AI Engine (BYOK):** `AiClientService` (OpenAI-compatible HTTP client), `StrategyAiService` (generator prompt rekayasa psikologis Misi 2 & 3), `UserAiSetting` model dengan `api_key` terenkripsi (Laravel AES-256 cast).
*   **Database:** MySQL 8.0 (Container `crm_db`, host port `33091`, default DB `crm_psikologis`).
*   **Cache & Queue:** Redis 7 Alpine (Container `crm_redis`, host port `63831`).
*   **Reverse Proxy:** Nginx (Container `crm_web`, host port `8484` -> expose port host ke tunnel `https://crm.pawandigital.id/`), kompresi Gzip aktif, immutable static caching 30 hari untuk aset `/build/`.
*   **Testing:** PHPUnit / Pest Feature & Unit testing (70 passed tests, 267 assertions, 100% pass).

### B. Tabel Database Utama
*   `users`: ID, nama, email, password, `role` (`user`|`admin`), `is_active` (boolean).

## 5. Panduan untuk AI / Developer di Masa Depan

### A. Perintah Cepat Lingkungan Docker
Jalankan perintah berikut di direktori root `/home/x/workspace/crm_ai`:
```bash
# Menyalakan seluruh service di background
docker compose up -d

# Memeriksa status kesehatan container (app, web, db, redis)
docker compose ps

# Membaca log Octane FrankenPHP
docker compose logs -f app

# Masuk ke terminal container app
docker compose exec app bash
```

### B. Optimasi Cache Produksi Laravel (Octane Ready)
Setiap kali melakukan perubahan konfigurasi `.env`, route, atau view Blade di lingkungan produksi:
```bash
# Bersihkan dan cache ulang seluruh layer konfigurasi
docker compose exec app php artisan optimize:clear
docker compose exec app php artisan config:cache
docker compose exec app php artisan route:cache
docker compose exec app php artisan view:cache

# Restart worker Octane agar konfigurasi baru dimuat sempurna
docker compose restart app
```

### C. Menjalankan Automated Testing Suite
```bash
# Menjalankan seluruh test Feature & Unit
docker compose exec app php artisan test
```

### D. Cara Menaikkan `APP_VERSION` Saat Rilis Fitur Baru
1. Perbarui nilai `APP_VERSION=X.Y` di `.env` dan `.env.example`.
2. Perbarui nilai default versi di `config/app.php`:
   ```php
   'version' => env('APP_VERSION', 'X.Y'),
   ```
3. Bersihkan cache config:
   ```bash
   docker compose exec app php artisan config:clear && docker compose exec app php artisan config:cache
   docker compose restart app
   ```
4. Komponen `<x-footer />`, halaman Login, dan diagnostik `/system-health` akan langsung menampilkan versi baru secara otomatis.
