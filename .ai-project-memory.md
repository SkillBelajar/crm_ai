## 1. Visi & Konsep Inti (5W + 1H)

### **What (Apa itu AI Psychological CRM?)**
Platform SaaS Gratis berbasis manajemen relasi pelanggan (CRM) yang dilengkapi kecerdasan buatan psikologis dengan pendekatan **"Pendengar & Pengendali"**. Sistem tidak hanya mencatat data kontak atau riwayat obrolan, melainkan menganalisis dinamika psikologis, membaca motif tersembunyi prospek, dan mengarahkan percakapan menuju kesepakatan bernilai tinggi tanpa gesekan.

### **Why (Mengapa dibangun?)**
Kebanyakan tim sales dan pemilik bisnis kelelahan (*burnout*) karena melayani calon klien yang tidak serius (*ghosting*, *window shoppers*, atau "lilin yang habis membakar dirinya sendiri"). CRM konvensional hanya berfungsi pasif sebagai tempat pencatatan, tanpa instrumen pengendali psikologis yang melindungi energi tim dan menyaring prospek berbobot.

### **Who (Untuk Siapa?)**
- Business Owners, Solo-founders, Agensi Jasa, dan Tim Penjualan B2B / High-ticket.
- Pengguna yang menginginkan alat bantu closing cerdas dengan privasi penuh dan efisiensi biaya melalui model **BYOK (Bring Your Own Key)**.

### **Where (Di Mana dan Bagaimana Diakses?)**
- Web application responsif (Desktop & Mobile) yang berjalan di infrastruktur berbasis container Docker.
- Mendukung integrasi webhook dan channel pesan (WhatsApp, Webchat) untuk mendengarkan percakapan secara langsung.

### **When (Kapan Digunakan?)**
- Sepanjang siklus penjualan: mulai dari perkenalan pertama (*lead discovery*), tahap negosiasi penawaran (*conditional framing*), hingga penguncian komitmen final.

### **How (Bagaimana Bekerjanya?)**
Mengoperasikan **3 Misi Utama Psikologis** yang didukung orkestrasi model AI melalui endpoint mandiri:
1. **Pancing & Catat (Active Elicitation & Pattern Capture):**
   Mendengarkan aktif kebutuhan terselubung dan *pain points* mendasar prospek tanpa terlihat menginterogasi. Mengklasifikasikan tipe kepribadian dan motif pembelian secara rahasia.
2. **Filtrasi Anti-Lilin (Conditional Yes):**
   Mencegah tim terbakar habis oleh prospek *toxic*. Menggunakan teknik psikologis *Conditional Yes* (Memberikan persetujuan hanya jika prospek memenuhi prasyarat tertentu seperti anggaran, timeline, atau komitmen).
3. **Kunci Kontrak Psikologis 24 Jam:**
   Membangun rasa urgensi internal yang elegan melalui batas evaluasi 24 jam untuk mengikat momentum psikologis prospek sebelum energi keputusan mendingin.
4. **BYOK Custom AI Endpoint (OpenAI-Compatible):**
   Pengguna bebas menghubungkan kunci API mereka sendiri (OpenAI, DeepSeek, vLLM, Ollama, Groq, OpenRouter) tanpa mark-up biaya dari platform.

## 2. Tech Stack & Spesifikasi Sistem

| Layer | Teknologi | Keterangan |
|---|---|---|
| **Container Engine** | Docker & Docker Compose | Arsitektur multi-container terisolasi |
| **Worker / Concurrency** | Laravel Octane + FrankenPHP (PHP 8.4) | High concurrency memory-resident worker |
| **Web Server** | Nginx Alpine (Reverse Proxy) | Reverse proxy ke `app:8000`, direct static caching |
| **Backend Framework** | Laravel 13 (Core 12.x/13.x) | Modern enterprise PHP framework |
| **Dynamic Reactive UI** | Livewire 3 + Alpine.js | Reaktivitas real-time tanpa SPA overhead |
| **Styling Engine** | Tailwind CSS v4 (`@tailwindcss/vite`) | Desain Executive Minimalist, dark-mode first |
| **Database** | MySQL 8.0 (Persistent volume `mysql_data`) | Database `crm_psikologis` |
| **Cache, Session, Queue**| Redis Alpine (Persistent volume `redis_data`) | Store, session, dan queue redis |
| **Version Variable** | `APP_VERSION=0.1` | Ditampilkan global via `resources/views/components/footer.blade.php` |

## 3. Docker Service & Port Mapping

| Service Name | Container Name | Port Internal | Port Host Default | Keterangan |
|---|---|---|---|---|
| `app` | `crm_app` | `8000` | - | Octane FrankenPHP Application Worker |
| `nginx` | `crm_web` | `80` | `8484` (atau `APP_PORT`) | Reverse proxy publik & static asset handler |
| `mysql` | `crm_db` | `3306` | `33091` | MySQL Database Engine |
| `redis` | `crm_redis` | `6379` | `63831` | In-memory Cache & Session Store |

*Catatan Port:*  
Port host Nginx dipetakan ke `8484` (variabel `APP_PORT=8484` di `.env`) karena port `8080`, `8081`, `8082`, `8083` di host server ini telah dialokasikan untuk layanan lain (`ljk_web`, `invoice_web`, `radar_web`, `news_backend`).
