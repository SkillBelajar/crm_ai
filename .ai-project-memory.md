# .ai-project-memory.md — Continuous Project Memory

## 1. Identitas & Visi Proyek (5W + 1H)
*   **What:** SaaS CRM Psikologis *"Pendengar & Pengendali"* (MindControl CRM). Alat bantu percakapan taktis berbasis AI Mandiri (BYOK) yang dirancang untuk para negosiator, konsultan, dan tim sales tingkat eksekutif.
*   **Why:** Mencegah sindrom "bakar lilin" (energi tim terkuras melayani prospek tanpa komitmen). Membalik dinamika percakapan dengan teknik mendengarkan aktif 80%, filtrasi *Conditional Yes*, dan penguncian komitmen dalam siklus 7 hari.
*   **Who:** Pengusaha solo, konsultan bisnis, agensi, dan tim sales B2B berenergi tinggi.
*   **Where:** Self-hosted / Cloud (Laravel 13 FrankenPHP Octane containerized), dapat diakses di jaringan lokal maupun tunnel publik (`https://crm.pawandigital.id/`).
*   **When:** Pembangunan bertahap 9 Slice (Target aktif: Versi 0.2).
*   **How:** Didukung AI Mandiri (BYOK - Bring Your Own Key) yang mendukung endpoint lokal / remote OpenAI-compatible, arsitektur event-driven ultra-cepat via Laravel Octane, Livewire 3, dan Tailwind CSS v4.

---

## 2. Tech Stack & Environment
*   **Framework:** Laravel 13 + Laravel Octane (FrankenPHP worker, PHP 8.4).
*   **Frontend:** Livewire 3 + Alpine.js + Tailwind CSS v4 (@custom-variant dark, JetBrains Mono & Plus Jakarta Sans).
*   **Database:** MySQL 8.0 (Container `crm_db`, host port `33091`).
*   **Cache & Queue:** Redis 7 Alpine (Container `crm_redis`, host port `63831`).
*   **Reverse Proxy:** Nginx (Container `crm_web`, host port `8484` -> expose port host ke tunnel `https://crm.pawandigital.id/`).
*   **Testing:** PHPUnit / Pest Feature & Unit testing.
